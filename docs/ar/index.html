OCR عربي مفتوح المصدر

نقطة: أدق نظام مفتوح المصدر للتعرف الضوئي على النص العربي

يحوّل «نقطة» صور الصفحات والمستندات الممسوحة ضوئيًا وملفات PDF العربية إلى نص أو Markdown. وهو الأول على معياري التعرف الضوئي العربي العامّين، وينقل التشكيل المطبوع كما هو، ويعمل على أجهزتك حتى الهاتف.

تحويل PDF إلى نص

العناوين والقوائم والجداول بصيغة HTML، لكل صفحات الملف.

التشكيل كما هو مطبوع

النص المشكول يحتفظ بحركاته، وغير المشكول يبقى دونها.

الجداول

جداول من اليمين إلى اليسار ومن اليسار إلى اليمين، بترتيب أعمدتها.

البطاقات وجوازات السفر

قراءة منطقة MRZ مع التحقق من أرقام الفحص.

دون إنترنت

على خوادمك أو حاسوبك أو هاتف أندرويد وآيفون.

الاستخدام في بايثون

pip install "nuqta-ocr[vllm]"   # Linux + NVIDIA GPU, fastest
pip install "nuqta-ocr[fast]"   # transformers with fast kernels
pip install nuqta-ocr           # transformers only
from nuqta import OCR

if __name__ == "__main__":
    ocr = OCR("nuqta-4b")          # or "nuqta-0.8b" for small GPUs
    print(ocr.read("page.jpg").text)                     # tashkeel only where printed
    print(ocr.read("scan.pdf", mode="markdown").text)    # headings, lists, HTML tables
    print(ocr.read("passport.jpg", mode="id").fields)    # MRZ fields with check digits

أسئلة شائعة

ما أفضل برنامج OCR عربي؟

على المعيارين العامين للتعرف الضوئي على النص العربي، حقق نموذج Nuqta-Arabic-OCR 4B أفضل النتائج المنشورة: معدل خطأ في الحروف 0.106 على KITAB-Bench، ونتيجة 82.8 على Misraj-DocOCR، متقدمًا على Gemini وGPT وBaseer. وهو مفتوح المصدر برخصة Apache-2.0.

هل يحافظ على التشكيل؟

نعم. ينقل التشكيل المطبوع في الصفحة كما هو، ونادرًا ما يضيف حركات غير موجودة فيها.

كيف أحوّل ملف PDF عربي إلى نص؟

ثبّت المكتبة بالأمر pip install nuqta-ocr، ثم استخدم OCR('nuqta-4b').read('file.pdf').text، أو جرّب الصفحة التجريبية في المتصفح دون تثبيت.

هل يعمل دون إنترنت؟

نعم. يعمل على خوادمك أو حاسوبك أو هاتفك دون اتصال، فلا تخرج مستنداتك من أجهزتك.

هل هو مجاني؟

نعم، النماذج والمكتبة مجانية ومفتوحة المصدر، ويجوز استخدامها تجاريًا.
