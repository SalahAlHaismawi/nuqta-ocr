Arabic OCR guides

How to use Nuqta OCR for common Arabic OCR jobs.

  • Convert Arabic PDFs to text in PythonExtract Arabic text from scanned or image-only PDFs, with tashkeel and tables, using the open-source Nuqta OCR library.
  • A more accurate alternative to Tesseract for ArabicTesseract misses about half of the characters on the KITAB-Bench Arabic benchmark. Nuqta OCR cuts the error rate five-fold and keeps tashkeel.
  • Arabic OCR that keeps tashkeel (diacritics)Most OCR drops Arabic diacritics or invents them. Nuqta copies the tashkeel printed on the page and almost never adds any.
  • Read Arabic ID cards and passports with OCRExtract MRZ fields with ICAO check digits from passports, visas and ID cards, and read Arabic ID text, on your own servers.
  • Run Arabic OCR offline on CPU, laptop or phoneUse the GGUF builds of Nuqta OCR with llama.cpp, LM Studio and similar apps, or the Android and iPhone apps.
